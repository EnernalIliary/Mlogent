### 1.1 时间窗

```js
function firstRecent(p, winSec) {
    if (p == null) return false;
    var rec = GTB_FIRST[uuidOf(p)];
    if (rec == null || rec.done === true) return false;
    var win = LIB.toInt(winSec, 0) * 1000;
    if (win <= 0) return true;
    return (nowMs() - LIB.toInt(rec.t, 0)) <= win;
}
```

`firstBreakCheck` 里插在「开关判断」之后、「取 e.tile」之前：

```js
if (!firstRecent(p, cfg0.thInteractWindow)) { firstClear(p); return; }
```

窗口 <= 0（理论上被 `clampInt` 挡掉了）时不做时间限制。

### 1.2 库存还原

- 快照：`content.items()` / `content.liquids()` 的 Seq 逐项 `m.get(x)`，只收数量 > 0（液体 > 0.0001）。
  不用 `ItemModule.each(ItemConsumer)` —— 那是 Java 单方法接口，无头环境里传 JS 函数不保证被认。
- 还原：`b.items.clear()` → 逐项 `b.items.set(item, amount)`；液体同理 `clear()` + `set(liquid, amount)`。
  每个调用单独 `try`，某项失败不影响其它项。
- `restoreTile` 里的顺序：air 守卫 → `setBlock` → 血量比例 → `configured` → `restoreInventory`。
