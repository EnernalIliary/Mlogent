# 大肥鱼的调试世界

一张给逻辑调试用的空白世界：全域 **染色地板**（colored-floor），8 格细网格 + 32 格主线 + 中心十字，
正中一个 `core-shard`。没有地形、没有矿、没有敌人 —— 想量什么东西，都只有你自己的建筑。

- 文件：`maps/大肥鱼的调试世界.msav`（128x128，6.9 KB）
- 生成器：`tools/mapgen.py`（图片/空白 → 染色地板 → .msav）
- 预览：`out/map_preview.png`（4× 放大）
- 服务器名：`world.execute(Mindustry)`；加入地址：`192.168.3.11:<gamePort>`（默认 15000，见 `world_status.gamePort`）

## 1. 这块地长什么样

| 用途 | 颜色 | 说明 |
| --- | --- | --- |
| 底色 | `#232732` | 整张图的地板 |
| 8 格细线 | `#2c3242` | 每 8 tile 一条 —— 正好一个逻辑链接范围（`8*10=80wu`）的十分之一，摆建筑时数格子用 |
| 32 格主线 | `#39415a` | 每 4 条细线加粗一次，128 的地图被切成 4x4 个大区 |
| 中心十字 | `#4c5a7a` | x=64 与 y=64 两条贯穿线，核心就在交点 |
| 交点亮点 | `#55617e` | 每 8 格网格交点一个点，数格子不用一格一格点 |
| 半径圈 | `#2f7f8f` | 以中心为圆心 r=10 / 20 / 40 格：分别对应逻辑链接范围（80wu=10 格）、常用集结点、大范围测试 |

Mindustry 的 y 轴朝上，图片第 0 行当作地图**顶部**（`--flip-y` 默认开）。

## 2. 规则

host 之后由守护进程钉死（存档里的 rules 会被 headless 覆盖，所以写死在 `world_server._boot`）：

```
waves = false          没有波次，不会被敌人打断
infiniteResources = true   核心不消耗，专心调逻辑
canGameOver = false    核心被打爆也不结束
logicUnitControl = true    允许逻辑处理器控制单位（`ubind`/`ucontrol`，否则整段静默跳过）
unitCap = 200
```

## 3. 调试手段（MCP 工具）

| 工具 | 干什么 | 典型用法 |
| --- | --- | --- |
| `world_spawn` | 造兵（黄金角螺旋铺开，不叠点） | `{type:"poly", count:8, x:64, y:64, radius:6}` |
| `world_kill_units` | 清兵（可按队/半径） | `{}` 全清；`{team:"crux", radius:20, x:64, y:64}` 局部 |
| `world_clear_buildings` | 清建筑（默认保留核心） | `{radius:20, x:64, y:64}` |
| `world_reset` | 恢复到刚开图的干净状态 | `{}`（默认不踢人）；`{hard:true}` 才 stop+host |
| `world_switch_map` | 换图 / 重载当前图，玩家不掉线 | `{map:"Fork"}`、`{}` 重载当前图 |

整条调试回路：`world_spawn` 造兵 → `world_place` 摆处理器/容器 → `world_logic_set` 灌代码 →
`world_logic_vars` 读变量 → `world_kill_units` + `world_clear_buildings` 收拾 → 需要重置就 `world_reset`。

**重置不踢人**：`stop` + `host` 会把所有玩家断开，改用引擎自己的换图路径就能保住连接 ——
`nextmap <图>` 只是登记「下一张图」，`gameover` 触发 `loadMap`（日志 `Loading map...` → `Map loaded.`），
NetServer 的连接表不动，客户端自己重载新地图。实测：换图前后 `players` 都是 1，日志里没有任何
`disconnected`，世界 tick 归零、建筑与单位清空。`world_reset` 默认就走这条路（`{hard:true}` 才回到
stop+host）。注意换完要重新钉一遍规则（waves=off / infiniteResources=on），`switch_map` 已自动做。

## 4. 换个尺寸 / 换成自己的图

```powershell
# 空白图：换成 256x256，网格 16/64，加半径圈
python tools/mapgen.py --size 256 --grid 16 --major 64 --rings 20,40,80 -o maps/big.msav

# 图片：逐像素变成染色地板（一张 128 像素宽的像素画正好一格一像素）
python tools/mapgen.py --image art.png --size 128 --fit stretch --resample nearest -o maps/art.msav

# 照片：线性插值混色 + contain 留边，看起来更接近原图
python tools/mapgen.py --image photo.jpg --size 128 --fit contain --resample lanczos --alpha-flag 2 -o maps/photo.msav
```

每个 tile 的颜色存在 `Tile.extraData`（int，RGBA 字节序），`ColoredFloor.drawBase` 直接 `Draw.color(extraData | 0xff)`；
alpha 字节不是透明度，而是混色标志（1 = 不与邻居混色、不画边框；2 = 两角插值 = 双线性过滤）。
`minimapColor()` 用的也是它，所以地图预览就是这张图本身。

## 5. 装进守护进程

```powershell
python tools/mapgen.py --size 128 --name '大肥鱼的调试世界' \
    --grid 8 --ticks 8 --major 32 --rings 10,20,40 -o maps/大肥鱼的调试世界.msav
Copy-Item maps/大肥鱼的调试世界.msav out/_world/server/config/maps/ -Force
python tools/world_client.py console "reloadmaps"
python tools/world_client.py console "host 大肥鱼的调试世界"   # 正在开服时先 stop
```

`world_server.py --map` 的默认值就是这张图，`--name` 默认 `Mindustry-localMCP`；
图不存在时打印 `[warn]` 并回退随机图，不会让守护进程整个起不来。

## 6. 为什么矿会「自己冒出来」

host 时 `Map.filters()` 读的是地图标签 `genfilters`；标签缺失/空串会走 `Maps.readFilters("")`，
它现造 35 个默认过滤器（每个 ore 脚印一条 `OreFilter` + `ScatterFilter`）在整张图上重新撒矿。
生成器固定写 `genfilters='[]'`，所以 file → 地图列表 → host 全链路都是 0 矿
（`ore=0`，可用 `world_js` 数 `tile.overlay() != air` 复核）。
