# Sidecar 后端重构验收

日期：2026-11-19。范围：MlogAgent 的 sidecar、技能工具发布与相关测试。提交信息以 Git 记录为准。

本轮重构完成，已执行检查没有失败项。知识库索引仍需重建，独立模组与联机世界的端到端验证不包含在本次通过结论中。

## 最终职责

| 模块 | 职责 |
| --- | --- |
| `tools/logicd.py` | 薄启动入口、旧调用兼容导出；导入时不创建默认应用 |
| `tools/logic_cli.py` | 参数解析与启动装配；查询命令不创建任务或聊天存储 |
| `tools/logic_runtime.py` | 应用配置、队列、聊天存储/上下文、心跳和生命周期 |
| `tools/logic_http.py` | 显式绑定应用的 HTTP 路由与请求响应处理 |
| `tools/logic_service.py` | 独立分析、组合、规划、签名与配置载荷 |
| `tools/logic_templates.py` | 确定性模板与离线意图匹配 |
| `tools/logic_links.py` | 链接解析、相对坐标与区域候选分析 |
| `tools/logic_models.py` | 模型地址处理、列表查询、探测与脱敏视图 |

任务队列和聊天代码检查直接调用业务层。聊天不再反向查找或导入启动模块；后台线程继承显式应用绑定。并发队列初始化有锁保护，应用关闭可重复调用。

## 发布收尾

- 根目录 `tools/` 为唯一工具源码；测试直接导入它。
- 技能工具副本退出版本管理，本机已有安装文件保留。
- 技能包从 Git 已跟踪文件的当前工作树构建，不收集本机未跟踪脚本或旧安装副本；目标已存在时拒绝覆盖。
- 验证结束清理生成缓存，ZIP 目录顺序与时间戳固定。
- 工具链独立包不含技能创作文档，明确跳过 `skillpack`；源码 checkout 仍必须执行该检查。
- 发布流程在路径替换后重新生成发布树清单，修复原清单仍描述源码字节的问题。

## 环境限制

完整门禁跳过 `quickcheck`、`rhinoparity`、`ui`、`package`、`gtb`、`gtbprobe`：相关独立模组未作为本 checkout 的输入。因此未验证游戏模组界面、完整模组安装包或冻结 EXE。

`differential` 的静态契约通过，实时端到端部分因没有运行中的联机世界而跳过。

`kb` 报告本地索引旧于修改后的源码；本次未重建向量知识库。需要更新检索快照时运行 `python tools/kb.py build`。

## 后续使用

新业务调用使用 `logic_service`，HTTP 装配使用 `logic_http.make_handler(application)`，嵌入式运行使用 `logic_runtime.Application`。

旧的 `logicd.analyse/compose/plan/region` 与运行期查询入口保留。直接修改运行期配置时使用 `logicd.APP`，不要给兼容模块的动态字段重新赋值。

技能构建：`python tools/build_skills.py --out dist/skills-<版本>`。正式发布入口：`python tools/dev/_build_release.py <版本>`。本轮没有对外发布。
