# E03 变量与内存边界

## 一句话

mlog 每个变量是一个 `LVar`，只有 **number / object / null** 三种可观测状态（外加 const 标志），没有字符串、没有数组、没有 map；所有「复杂数据」都靠 memory cell 与对象引用拼。

## 规则 / 公式

### 1. LVar 的三个字段与四种状态

| 字段 | 类型 | 含义 |
|---|---|---|
| `isobj` | boolean | 是否对象位 |
| `objval` | Object | 对象值；`null` 即「null 状态」 |
| `numval` | double | 数字值（仅 `isobj=false` 时有意义） |
| `constant` | boolean | 是否常量（set 不可写） |

| 状态 | 判定 | `bool()` | `num()` | `numOrNan()` |
|---|---|---|---|---|
| 数字 | `!isobj` | `abs(num) >= 1e-5` | `numval` | `numval` |
| 对象 | `isobj && objval!=null` | true | **1** | 1 |
| null | `isobj && objval==null` | false | **0** | **NaN** |
| 数字 NaN/Inf | `!isobj && invalid(numval)` | false | **0** | NaN |

⇒ 「null 与 0 相同」只对 `num()` 成立，对 `numOrNan()` / `bool()` 不成立。

### 2. 写入路径的三条规则

```java
// LVar.java:87-97  setnum
if(invalid(value)){ objval = null; isobj = true; }   // NaN/Inf 直接变 null
else { numval = value; isobj = false; }
```

| 规则 | 代码 | 效果 |
|---|---|---|
| NaN 赋值 | `setnum` :87-97 | 变量变成 **null 对象**，不是 NaN 数字 |
| 数字变量被 set(LVar) | :110-118 | 源的 numval 若 invalid ⇒ 写 **0** |
| 常量 | `constant` | `set` 静默丢弃（@ipt/@unit/@links 等） |

### 3. memory cell

| 类型 | 容量 | 来源 |
|---|---|---|
| memory-cell / memory-bank | **64 / 512** 格 | content/Blocks.java:6872-6883 |
| world memory cell | **512** 格 | Blocks.java:6962-6969 |
| 读取容量 | `@memoryCapacity` | MemoryBlock.java:86 |

`read cell <地址> <结果>` / `write cell <地址> <值>`：地址是整数下标，**越界不报错**，按 Java 数组语义处理（写越界抛异常由引擎吞掉 ⇒ 表现为无效果，【U】精确行为待实验）。

### 4. 文本缓冲

| 缓冲 | 上限 | 行为 |
|---|---|---|
| `textBuffer` | **400** 字符 | 满则**直接丢弃**新文本（LExecutor.java:1057/:1100），不抛错 |
| `format` 结果 | 400 | 超长截断（:1155-1156） |
| `message` 方块 | 400 | 超长**拒绝写入**（MessageBlock.java:42） |
| 聊天 | 150 | `Vars.maxTextLength`（与 print 无关） |

### 5. @links 与链接数

`LogicBlock.updateLinks()`（:582-599）把 `@links` 写成**有效链接数**（非配置数）：链接名无效时不计数 ⇒ 读 `@links` 做循环上界是安全的。

### 6. 变量数量上限

【U】未核实。源码未见「每处理器变量数上限」常量（变量是 `Map<String,LVar>` 按需创建），但实际受内存与 `LParser` 行数上限 1000 约束；需要一次「创建 5000 个不同名变量」的实验确认是否会 OOM。

## 实测与反例

- 【S】`sensor result cell @memoryCapacity`：memory-cell=64、memory-bank=512、world-cell=512（`MemoryBlock.java:84-88` 直接返回 `memoryCapacity`；实例值见 `Blocks.java:6875/6881/6967`）。
- 反例（不成立边界）：**「memory cell 能存对象」不成立**。cell 只存 double；存单位/方块引用必须靠 `flag` 或直接持有引用变量。
- 反例：**「print 会自动换行/扩容」不成立**。400 字符硬上限，且 print 不追加换行，需要显式 `print "\n"` 式换行符。
- 【S】memory 越界：**读出 null（`Double.NaN`）**、**写入静默丢弃** —— `MemoryBlock.java:67-68` 注释 `Return null when out of bounds. (instead of 0)`，`:79` 越界 `return`。未写入过的合法地址读出 0（`double[]` 默认值）。 [src: MemoryBlock.java:64-81]

## 常见误解

1. 「NaN 是一个值」——在 mlog 里它等价于 null 状态。
2. 「@links 是配置的链接数」——是**有效**链接数。
3. 「变量可以存字符串」——只能用 print/format 生成文本流，不进入变量。
