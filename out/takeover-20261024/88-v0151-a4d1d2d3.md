## 1 为什么改（问题与证据）

| 现象 | 根因 | 证据 |
|---|---|---|
| 一批处理器里有的作业被预检拒 `link-name-not-bound` | `startJobBatch()` 给整批同一个 `desc`，模型不知道「同一句话发给了几台、我跟别人链接表不同」，照抄隔壁那台的链接名 | 历史被拒作业里该类 2 次；`tools/mlogprovider.py` 的白名单只按「这一台」的 links 生成 |
| 框还在时想改一台，只能开工作区窗 | 框角只有「查看 / 取消」；`wsImproveBatch()` 要先进工作区对话框 | `MlogAuxiliary/scripts/main.js` 的 `jobButtonLayout`（v0.14.2 两按钮） |
| 出错提示一闪而过，回头看不到 | `hint()` 只是 `Vars.ui.showInfoFade(String(text))`，不留存 | `main.js` 的 `hint()` |
| 作业管理窗只列最近 24 个、不能过滤 | 客户端写死 `limit=24`，没有过滤 UI | `renderManager()` 的 `/jobs?all=1&limit=24` |

## 2 改了什么

- **A4 批次可辨识**：`jobBody(b, desc, wsInfo, batch)` 把 `{i, n}` 写进作业体；`tools/jobqueue.py` 的 `normalize()`
  解析并夹紧（`n >= 1`、`1 <= i <= n`，非对象抛 `ValueError`），**`batch` 不进 `job_id()`**（同批多台仍靠 `-2/-3`，
  与 v0.12.2 一致）；`build_prompt()` 输出 `batch: the same sentence was sent to N processors; this is #i`
  与「每台有自己的链接表，照抄别台会被拒」，另加规则「只用白名单里的链接名，缺块就在 needs_links 里说」。
- **D1 框内续聊**：框角第三个按钮「续聊」（即时绘制 `{id: "follow", label: "续聊"}` + 原版控件按钮两套），
  `jobFollowPick()` 认光标下那台（必须在框里）或框里唯一那台，`jobFollowAsk()` 弹描述框（预填工作区 notes 或上次描述），
  `jobFollowSubmit()` 走 `wsAttach` + `wsImprovePayload` 投 `mode: improve`，作业挂回当前框，不新建框、不影响同批其它台。
- **D2 提示留痕**：`hint()` 写 `LAST_HINT{text, at}`；设置页新增「最近提示」段（点格子复制全文 + 清空）；
  `lastHintLblRefresh()` 逐层判类型（无头模拟器的 Cell 桩没有 `get()`，真机不受影响）。
- **D3 作业窗过滤**：`managerFilter {text, onlyBad, limit: 100}` + 纯函数 `jobHit(job)`；
  管理窗顶部「过滤：… / 只看失败 / 显示更多（+100，上限 200）」，列表显示「符合条件 X / Y 个」。
- 版本三处升 0.15.1；断言表 L2-81（**140 条**）；规划表、CHANGELOG、模组 README（三按钮、八段设置、续聊说明）同步。

## 4 坑

1. **补丁锚点要现查**：`d.cont.defaults().pad(4).left();` + `pane(host).height(320)` 这对在 `main.js` 出现两次
   （作业管理窗与工作区窗），只能改用「刷新」按钮行做锚点。
2. **探针前缀别自带**：`maiFilterProbe` 一开始返回 `"MAIFILTER:ok …"`，而 smoke 又以 `MAIFILTER2:` 作前缀打印，
   变成 `MAIFILTER2:MAIFILTER:ok …`，断言才露馅 —— 探针只回载荷，前缀由调用处加。
3. **旧断言会跟新功能打架**：v0.14.2 的红线要求框角按钮恰好是 `['cancel','view']`，加了第三个「续聊」就红；
   改成「前两个仍是 cancel/view」。
4. **无头模拟器的控件桩**：`Table.button()` 回的 Cell 在 `tools/mlogsim.py` 里没有 `get()`，
   `lastHintLblRefresh()` 必须先 `typeof … === "function"` 再调，否则每次 hint 都抛 TypeError。
5. `Queue.enqueue()` 仍是 `(job, created)`；`tools/mlogprovider.py` 的 `build_prompt()` 要求 `origin` 是 `{x, y}` 对象，
   用字符串探它会 `AttributeError`。
