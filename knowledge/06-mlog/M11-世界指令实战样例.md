# M11 World instruction examples

## 一句话

真实蓝图语料能为世界处理器指令提供可检索的参数排列和组合用法，但每条样例仍需经过版本和场景验证。

## 规则/公式

样例中的指令顺序以 `06-mlog/instructions.json` 的 `params` 为准，语料只用于补充真实写法和组合模式。

## Scope

These are short statements observed in the local logic corpus, rather than
hand-written textbook examples. The corpus was collected from seven public
schematic repositories and later expanded with processors extracted from local
Mindustry saves. The examples preserve the spelling and argument order that
appeared in the source files.

Observed code is evidence that a statement existed in a real blueprint. It is
not evidence that the surrounding program is correct or that the line is safe
on every Mindustry build. Run `mlog_check` and a world-processor simulation
before using a sample in a new blueprint.

## Frequently observed forms

### Execution speed

```mlog
setrate 1000
```

The argument is the target `@ipt`. This is a world-processor instruction.

### Tile reads and writes

```mlog
getblock block 检测点 8 12
setblock block @air x y @sharded 0
```

`getblock` and `setblock` use `layer` in the first slot. Coordinates are tile
coordinates. `building` can be read but is not a writable `setblock` layer.

### Unit and projectile creation

```mlog
spawn @crawler 198 69 90 2 BOSS true
spawn @mono DX DY 90 2 信标 true
bullet 子弹 @renale 2 X Y 角度 2 null 伤害 1 1 -1 -1
```

The `spawn` result slot receives a unit reference only when creation succeeds.
Names such as `BOSS`, `DX`, and `伤害` are ordinary variables from the source
program, not enum values.

### Status, rules, and flags

```mlog
status false @status-boss BOSS 10
setrule mapArea 10 0 0 270 140
setflag "向右" false
getflag 难1 "困难"
setprop @phase-fabric build 1000
```

The first `status` argument is the boolean `clear` field. Use `true` to clear
and `false` to apply. `setrule` changes global rules, and `setprop` changes a
world property. Both should be treated as global side effects.

### Messages and markers

```mlog
message announce 3 @wait
makemarker shapeText 序号 X 目标Y true
setmarker pos 序号 X 目标Y 0
setmarker flushText 序号 1 0 0
```

`message` consumes the current print buffer. `@wait` in the output slot makes
the processor yield until the message can be shown. A marker must be created
with `makemarker` before `setmarker` edits its properties.

### Effects, sound, and waves

```mlog
effect trail X Y 80 %16ffe5
explosion 2 X 发射Y 12 伤害 false true false true
playsound true @sfx-shotgun 1 0.2 0 x y true
spawnwave x y 0
```

Effects, sound, and cutscenes are presentation commands. They can be valid
mlog while having no visible result on a headless server.

## Source coverage

The local scan found 3,493 world-instruction occurrences across 1,427 mlog
files. The most common commands were `setprop` (726), `fetch` (688), `effect`
(362), `getflag` (310), `setrate` (257), and `setmarker` (247). Less common
commands are still represented in the machine-readable instruction table, but
the corpus has only 3 `spawnwave` examples and 8 `playsound` examples.

The downloader and extraction path is:

```text
tools/corpus/fetch_schematics.py
tools/corpus/fetch_repo_tarball.py
tools/corpus/extract_logic.py
tools/corpus/mine_idioms.py
```

The original corpus is intentionally excluded from release packages because it
is large and contains third-party material. This compact article is the
publishable derivative used by the MCP knowledge search.

## 实测与反例

语料中存在参数顺序错误、变量命名依赖和仅适用于世界处理器的代码。`status clear ...` 是典型反例，因为第一槽是布尔值而不是字符串命令。

## 常见误解

1. 语料中出现过不等于它在所有版本都有效。
2. 样例里的中文变量名不是枚举值，不能照抄成 `@` 常量。
3. `logic-corpus/` 是原始材料，在线发布使用的是本篇精简派生内容。
