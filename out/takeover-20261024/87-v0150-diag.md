## 2. 改动

### 2.1 A1 失败分类（`tools/mlogprovider.py`）

七类：`transport` / `http-status` / `bad-json` / `empty` / `truncated` / `unparsable` / `config`。

- `RETRYABLE = (transport, empty)`，按 `BACKOFF = (0.8, 2.0, 4.0)` 退避重试，最多 `RETRY_TOTAL = 3` 次。
- `truncated` 单独一条路：预算 ×4、超时 ×3，最多 `TRUNC_TOTAL = 4` 次；用尽或到 `TOKENS_CEILING` 就返回
  `_budget_hint()` 版本（点名 `--llm-max-tokens`）。
- 401/403/404 → `fatal=True`，作业立即 `failed`，不再重试。
- `_fail(kind, msg, budget, doc=None, **extra)` 是唯一出口；`doc` 里 `finish_reason == 'length'` 时把类别改写成 `truncated`
  ——否则「永久截断要说出预算开关」那条旧测试会红（第一版就是这么红的）。

### 2.2 A2 作业诊断（`tools/mlogprovider.py` + `tools/jobqueue.py`）

- provider 侧：`_diag(budget, **extra)`、模块级 `_usage(doc)`。
- 队列侧：`_record_attempt()` 向 `job['attempt_log']` 追加
  `{n, ms, provider, url, model, budget, finish_reason, prompt_tokens, completion_tokens, total_tokens,
  reply_chars, attempt, http_status, kind, error}`（只留非空项，`ATTEMPT_LOG_MAX = 8` 截尾），
  同时写 `job['diag']` / `job['model']` / `job['provider']`，finding 带 `kind`。
- `PROVIDER_EXHAUSTED = ('empty', 'transport')`：第二次仍同类失败就收手，`_exhausted_text()` 给一句人话
  （「endpoint returned an empty message N times in a row … raise --llm-max-tokens」）。

### 2.3 B1 并发 worker（`tools/jobqueue.py` + `tools/logicd.py`）

- `Queue(..., workers=N)`、`self.threads`；`_next()` 改名 `_claim()` 并**在同一临界区内**把 `state` 改成 `claimed`；
  `_run()` 接受 `queued|claimed`；`__init__` 把残留的 `running|claimed` 复位 `queued`；`drain()` 也走 `_claim()`。
- `tools/logicd.py`：`--jobs-workers`（默认 3）、全局 `JOB_WORKERS`、`Queue(..., workers=JOB_WORKERS)`。

### 2.4 C1+C2 sidecar 端口/身份/生命周期

服务端（`tools/logicd.py`）：

- `/health` → `{ok, protocol, version, pid, port, exe}`；顺手刷 `LAST_PING`。
- `POST /ping` 刷心跳；`POST /shutdown` 先回 `{"ok":true,"bye":true}` 再 `STOP.set()`。
- `--idle-exit SEC`：主线程 `STOP.wait(0.5)` 轮询，`time.time() - LAST_PING > idle_exit` 且队列里没有
  `queued/claimed/running` 作业时打印 `logicd idle for N s with no ping, exiting` 并退出。

模组侧（`MlogAuxiliary/scripts/main.js`）：

- `SIDE_IDLE_EXIT = 45`，拉起时 `--port 0 --idle-exit 45`（让系统挑端口），再用
  `sidecarLogPort(dir)` 从 `sidecar.log` 的 `listening on http://` 读回真实端口。
- `sidecarUrl()`/`sidecarPing()`（4 s 节流，只对自己拉起的进程发）/`sidecarVersionMismatch(h)`/
  `sidecarOurs(h)`（`h.exe` 含 `mlogauxiliary`）/`sidecarRetire(url, why)`（`POST /shutdown` → 700 ms → 重新拉起）。
- 版本不符：自己的就退役换新；别人的只提示「8765 上是另一份 sidecar（版本 X，本模组是 Y）：先把它停掉」。
- `sidecarStateText()` 加 `stale` 与 `已就绪（本模组启动）`。

### 2.5 A3 面板说人话（`MlogAuxiliary/scripts/main.js`）

- `JOB_WHY` 把 `kind` 映射成一句中文；`jobKindOf`/`jobWhyLines`/`jobLastAttempt`/`jobAttemptLine`/`jobEvidenceLines`。
- done 分支打「模型：http · m-a」与「第 N 次调用：…」；rejected/failed/cancelled 分支在 findings 后打
  「为什么：…」与 `--- 诊断 ---`；重试中也带 why。
- 探针 `api.maiJobDiagProbe(jobJson)` → `MAIJOBPANELDIAG:ok why=N ev=N first=… line=…`。

## 4. 本轮踩的坑

1. **补丁锚点撞车把整个类删了**：第一版 `tools/mlogprovider.py` 补丁锚点取
   `def __call__(self, job, hint=None):\n        prompt = build_prompt(job, hint)`，但 `ScriptedProvider.__call__`
   也以同样两行开头且位置更靠前 ⇒ 替换掉了 `HttpProvider` 整个类 + 三个常量 + `Recorder`。
   `logicd.py` 立刻 `AttributeError: module 'mlogprovider' has no attribute 'DEFAULT_MAX_TOKENS'`。
   修法：`git checkout -- tools/mlogprovider.py`，脚本先定位 `class HttpProvider:` 再在其后找 `__call__`，
   并加 `assert "DEFAULT_MAX_TOKENS = 4096" in flat` / `assert "class Recorder" in flat`。
2. **同一常量被写了两遍**（`REASONING_MAX`）⇒ 去重脚本合并。
3. **把 CRLF 文件改成 LF**：用一行 `python -X utf8 -c "... write_text(..., newline='\n')"` 改
   `tests/logicd/run_logicd_tests.py`，`git diff --stat` 立刻从 153 insertions 变成 1700/1550 全文件。
   已改回 LF（仓库 `core.autocrlf=false`、无 `.gitattributes`，HEAD blob 就是 LF）。
   **取证陷阱**：`git show HEAD:file | python -` 在 PowerShell 里会把行尾重编码成 CRLF，看着像「HEAD 是 CRLF」，假的；
   真判据是 `git diff --stat`。
4. **stub 太不像真端点**：`_StubEndpoint` 的成功回复里没有 `usage`/`model`，A2 的「token 计数」测试因此失败；
   把 stub 改成真端点形状（`model` + `finish_reason: 'stop'` + `usage`）后才有意义。
5. **`Queue.enqueue()` 返回 `(job, created)`**，把返回 tuple 当键用会 `TypeError: unhashable type: 'dict'`。
6. **ui smoke 红线不能带行尾注释**：`sidecarPing();  // v0.15.0` 被 `code_only` 剥成 `sidecarPing();` 之前的形态 ⇒
   红线写成裸 `sidecarPing();`。
7. **红线锚点必须 grep 现场**：`for needle, why in (('function jobCostLines(',` 在文件里根本不存在（真实是
   `('function jobAssumptionLines(',` 那一组），脚本断言失败、**整段没写盘**，但 smoke 仍 EXIT=0 ⇒ 差点误判通过。
