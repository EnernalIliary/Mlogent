# M01 执行模型总览

## 一句话

处理器不是"脚本解释器进程"，而是**每 tick 被游戏推一下的累积器**：每 tick 累加 `ipt × Δt` 点预算，攒满 1 就执行一条指令，执行位置由可写的 `@counter` 决定。

## 规则 / 公式

### 1. 每 tick 的预算（accumulator 池）

`LogicBlock.java:564-579` 的 updateTile() 本体：

```text
accumulator = min(accumulator, maxInstructionScale * ipt)   // 先削顶
while(accumulator >= 1):
    executor.runOnce()          // 执行一条指令，@counter 自增
    if(executor.yield): break   // 让出：break 写在 accumulator-- 之前
    accumulator -= 1
accumulator += edelta() * ipt   // 累加在循环之后，顺序有意义
```

| 事实 | 依据 |
|---|---|
| 预算是**跨 tick 累积**的池子，不是每 tick 重置的额度 | `accumulator += edelta()*ipt` 从不清零 |
| 单 tick 最多积攒 `maxInstructionScale × ipt` 点，多余丢弃（削顶） | `if(accumulator > maxInstructionScale*ipt) accumulator = maxInstructionScale*ipt` |
| 会**让出（yield）的指令不消耗预算** | `break` 在 `accumulator--` 之前 |
| 长期平均吞吐 = `ipt` 条/tick；60 tick/s ⇒ `ipt×60` 条/秒 | 由上式取稳态 | [src: knowledge/VERSION.md:1]

### 3. 程序与指针

- 一条 mlog 语句编译成一个 `LInstruction`，存进数组；`@counter` 就是该数组下标。
- `runOnce()`（LExecutor.java:111-121）：
  ```java
  if(counter.numval >= instructions.length || counter.numval < 0) counter.numval = 0;
  instructions[(int)(counter.numval++)].run(this);
  ```
  ⇒ **指针越界不会崩，只会回 0**；`@counter` 是 double，被强转 int。
- `@counter` 是**唯一能 `set` 的引擎内建变量**（`LAssembler.putVar` 建的，非常量）；`@unit`/`@ipt` 都是 `putConst`，`set` 被静默丢弃（见 M02）。
- 程序条数上限 `LExecutor.maxInstructions = 1000`；解析 LParser.java:185 用同一常量，编辑器 LCanvas.java:148 `statements.truncate(1000)`。
- 注释不进指令数组，**不占 `@counter` 下标**（LParser 解析期剥离 `#`/`//`）。

## 实测与反例

- ✅【E】`print @tick` + `end` 连续输出，`end` 之后语句永不执行（断言表 L1-01/L1-02，claims.jsonl）。
- ✅【E】`jump -1 always` 不是 nop：`counter<0` 被归一化为 0，等于从头跑（L1-04）。
- 反例（不成立边界）：**"每 tick 正好执行 ipt 条"不成立**。micro 的 ipt=2，卡顿一帧后累积器可能攒到 `5×2=10` 并在后续 tick 突发——这是"逻辑在卡顿后突然加速"的机制来源。
- 反例：**"yield 的指令也吃一条预算"不成立**。`wait` 让出时 `accumulator` 不减，所以 wait 循环不会因预算被吃而变慢。

## 常见误解

1. "每秒固定跑 `ipt×60` 条。" —— 长期平均对，**瞬时不对**；卡顿会削顶丢预算，卡顿后会用池子突发。
2. "`@counter` 只能被 jump/end 改。" —— `set @counter x` 同样有效，且是文档化跳转手段。
3. "指令条数按行数算，注释也算。" —— 注释不占下标，`@counter` 是"语句序号"。
4. "world-processor 只是范围大。" —— 它的 max 是 1000（普通 40），且能跑 world 指令集。
