# v0.20.2 自由对话窗：宽度预算与入口位置（2026-11-02）

## 1. 用户报了三件事

- m03006：「MAI管理面板，左边的新对话窗口太大了已经超出左边了，修复一下。」
- m03017：「不对，新对话应该在右边的，你应该错误放在了左边」
- m03682：「现在的「＋ 新对话」按钮占满了整个左边的屏幕」（用户当时跑的是装机版 v0.20.1）

## 2. 取证

- 装机目录 `saves\mods\MlogAuxiliary\mod.hjson` = `version: "0.20.1"`，`last_log.txt` 里 `[mai] v0.20.1 ready, 87/87 console function(s)`，
  且没有任何排版 dump（v0.20.1 只有工作区的 `ws geom`，对话窗没有）⇒ 用户看到的就是 v0.20.1。
- `chatPlan()`（v0.20.1 当时在 main.js:4707）的算术：`availW = clamp(w - 56, 520, 1080)`、`listW = clamp(availW * 0.24, 190, 260)`、
  `detailW = max(300, availW - listW - 16)`。`16` 只算了「竖线 2 + 两侧 pad 7+7」，**没算** `d.cont.defaults().pad(3)` 的 3+3，
  所以 `d.cont` 的内容比 `availW` 宽 6 —— Dialog 是「内容多宽就多宽」，窗口被顶宽 6px，居中后左右各溢 3px；
  更关键的是 `availW` 已经从 `w - 56` 扣过一轮，屏幕窄时窗口本身贴近屏幕边缘，溢出更明显（用户说的「超出左边」）。
- `chatRefreshListBody()`：左栏顶部「＋ 新对话」= `width(Math.max(100, iw - 4))`，`iw = listW - 22` —— **≈ 整栏宽**，
  外面还套 `host.add(top).growX()`。画出来就是一条横贯左栏的大按钮 ⇒ 用户 m03682 说的「占满整个左边的屏幕」。
- `openJobManager()` 的 `chatBar`：「＋ 新建对话」(130) 在左、430 宽说明在右、外层 `growX()` ⇒ 整行拉到对话框边缘。

## 3. 改法

| # | 位置 | 改动 |
| --- | --- | --- |
| 1 | `chatPlan()` | 新增 `gapW = 22`（竖线 2 + 两侧 pad 7+7 + 外壳 pad 3+3），`detailW = max(300, availW - listW - gapW)`，
     | | `availW = clamp(w - 80, 520, 980)`、`availH = clamp(h - 220, 300, 680)`、`listW = clamp(availW * 0.21, 168, 224)`；
     | | 并保证恒等式 `listW + gapW + detailW === availW` |
| 2 | `openChatDialog()` | 两栏的 `Cell.get()` 存进 `CHAT_UI.listPane/detailPane`；输入行 cell 宽改 `availW - 6`、输入框宽 `availW - 160`；
     | | 底栏 `d.buttons.right()`，顺序 关闭 / 刷新 / 删除这段 / 新对话（新的在最右）；`d.show()` 后 `CHAT_UI.needGeom = true` |
| 3 | `chatRefreshListBody()` | 栏宽先夹（`NaN`/0 → 220，再 `listW - 22` 夹到 150..420）；标题行 = 「会话列表」+ 右侧固定 132 宽的「＋ 新对话」，
     | | 整行 `width(iw)`，不再 `growX` |
| 4 | `chatRefreshDetailBody()` | 首行加「对话内容」小标题；空态在**右栏**直接给「＋ 在这里开一段新对话」（210 宽） |
| 5 | `openJobManager()` | `chatBar` = 说明(360) + 弹簧 `add().growX()` + 「＋ 新建对话」(130) 靠右；整行 `width(600)` 与作业列表同宽 |
| 6 | 新增 `chatGeomDump()` | 仿 `wsGeomDump`：`CHAT_UI.needGeom` 置位后，`Events.run(ET.Trigger.draw, ...)` 第一帧 dump 一次
     | | `[mai] chat geom: dialog(...) title(...) scene=WxH listW= detailW= listPane(...) detailPane(...) input(...) host(...) #0 ...` |
| 7 | 探针 `api.maiChatUiProbe` | 期望值改 980/206/22/752；新增 `gapW`、恒等式、`chatPlan(920,760)` = 840/176/642、`detailW >= 300` |

## 5. 留给真机验

1. 打开对话窗（蓝图页底栏「MAI 对话」/ 工作区快照「＋ 对话」/ 作业管理「＋ 新建对话」三条路都试一次），窗口左右**都不该贴边**；
2. 左栏顶部应是「会话列表」+ 右边一个小「＋ 新对话」（约 132 宽），不再是一条占满左栏的大按钮；
3. 底栏「新对话」在最右；右栏没选会话时有「＋ 在这里开一段新对话」；
4. `saves\last_log.txt` 里应有一行 `[mai] chat geom: dialog(...)`，把这行发回来就能直接量宽度。
