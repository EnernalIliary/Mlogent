## 2 真根因：Groups.* 不是 arc 的 Seq

mindustry.entities.EntityGroup 只有 size() / index(int) / each(...)，**没有 get(int)**：

- 旧 seqGet() 是 try { return seq.get(i); } catch (e) { return null; }
- Rhino 里调用不存在的方法抛 TypeError，被 catch 成 null
- 于是 Groups.build / Groups.player 的每一次遍历都「长度对、元素全 null」
- 所有扫描（钍堆、爆混、病毒、applyBlacklistToOnline、playerByUuid）全部静默空转，日志一行错都没有

真机取证（out/_js_probe7.py / _js_probe8.py）：Groups.build.getClass().getName() = mindustry.entities.EntityGroup；
控制台 GB.get(0) 报 "Cannot find function get in object [...]"；GB.index(0) 正常。

修法：seqGet 依次试 get(i) → index(i) → items[i]，并加 seqEach()；自检钉住「能取到元素」。

## 3 其余四处

- 钍堆：readNum(b, "heat", 0)（先 public 字段，再反射）；判定阈值 0.0001；heat >= 0.999 时游戏自己 kill()，
  所以扫描周期 3000 → 1000 ms；只对「本来 enabled」的堆停用并通告一次，已在停用状态只补记（不刷屏）。
