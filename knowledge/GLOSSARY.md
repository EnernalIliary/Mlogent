# Glossary - Chinese, English, and legacy names

This file answers one question: **given a Chinese name, which English id and
which document does it mean?**

Three sources, each with its own job:

1. **The top half of this page (hand-written)** - concepts, system names and
   logic-processor jargon. These have no official English id, only a usage.
2. **The bottom half (between the `AUTO:BEGIN` and `AUTO:END` marker lines,
   generated)** - the four-column mapping for game entities: English
   id / official English name / official Chinese name / legacy and colloquial
   names. Generated by `knowledge/tools/gen_glossary.py` from
   `data/game/bundles/*.properties` and `data/game/aliases.json`.
   **Do not edit by hand.**
3. **`data/game/aliases.json`** - the machine-readable
   `id -> [official zh, legacy...]` map that `tools/game.py` searches.

## 2. The three layers of a name

One thing usually has three Chinese names. Pick by this rule:

| Layer | Example | Rule |
|---|---|---|
| **Official** | `parallax` = 差扰, `core-shard` = 初代核心 | Documents **must** use this layer (`bundle_zh_CN.properties` is the source of truth) |
| **Legacy** | 耀斑 (now 星辉), 金玻 (now 钢化玻璃), 碎片核心 (now 初代核心) | Kept only as search aliases; never in prose |
| **Colloquial** | 硅厂 (硅冶炼厂), 爆混 (爆炸混合物), 微处 (微型处理器) | Allowed in parentheses, never in a heading |

When a search finds nothing, swap the word in this order: official name,
English id, legacy name, colloquial name. `tools/kb_grep.py` and `mlog_kb`
match on the surface form, so swapping the word beats rewording the question.
